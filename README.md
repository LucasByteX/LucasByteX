## 🧠 Sobre mim

Sou estudante de Engenharia de Computação com foco em dois mundos que se complementam: **sistemas embarcados e desenvolvimento web**. Trabalho com microcontroladores como ESP32, Arduino e STM32, e também desenvolvo aplicações web e mobile com JavaScript, React Native e PHP.

Acredito que hardware e software juntos têm o poder de resolver problemas reais — e é isso que me motiva a aprender todos os dias.
